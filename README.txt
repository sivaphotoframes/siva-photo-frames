SIVA PHOTO FRAMES — WEBSITE STARTER
====================================

Files:
- index.html: responsive storefront homepage and order enquiry form
- styles.css: visual styling
- script.js: product selection and WhatsApp order-enquiry flow
- assets/siva-photo-frames-logo.png: brand logo artwork

BEFORE PUBLISHING:
1. Open script.js and WhatsApp is configured as +91 89390 15264 (country code + number, digits only).
2. UPI ID is configured as 8939015264@ptyes. Confirm it is correct and active before publishing.
3. Confirm product sizes, final prices, shipping charges, return/replacement policy and delivery timelines.
4. Test the form on mobile and desktop.
5. Free hosting option: GitHub Pages (static website hosting). Create a GitHub repository, upload the contents of this folder, enable Pages in repository Settings, then use the generated GitHub Pages URL. A custom domain such as sivaphotoframes.in requires a separately registered domain and DNS setup.

IMPORTANT LIMITATIONS:
- This is a front-end starter, not a live ecommerce backend.
- It does not store orders, upload customer photos to a server, process UPI payments, issue invoices or provide live courier tracking.
- Payment flow is manual UPI: confirm the final order total in WhatsApp. The configured UPI ID (8939015264@ptyes) is displayed on the page; customers should pay only after you confirm the order total. Verify the UPI ID is correct and active before publishing.
- The customer attaches their photo manually in WhatsApp after the enquiry opens.
- To accept online payments and manage orders securely, connect a hosted ecommerce platform/payment gateway after choosing a provider and completing its onboarding.
- Do not advertise the domain as live until domain ownership, DNS, SSL and hosting are configured.
